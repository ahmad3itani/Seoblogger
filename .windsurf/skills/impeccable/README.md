# Impeccable Skills - Installed

Impeccable is a design language system that helps AI create better frontend designs by providing:
- **1 Core Skill**: `frontend-design` with 7 domain-specific references
- **20 Commands**: For auditing, polishing, and improving UI/UX
- **Anti-Patterns**: Explicit guidance on what NOT to do

## 🎯 Available Commands

### Quality & Review
- `/audit` - Run technical quality checks (accessibility, performance, theming, responsive)
- `/critique` - UX design review with heuristics scoring
- `/polish` - Final pass before shipping
- `/normalize` - Align with design system

### Design Refinement
- `/colorize` - Improve color palette and contrast
- `/typeset` - Enhance typography and hierarchy
- `/arrange` - Optimize layout and spacing
- `/animate` - Add purposeful motion design

### Content & UX
- `/clarify` - Improve UX writing and labels
- `/distill` - Simplify and reduce cognitive load
- `/extract` - Extract design system from existing code
- `/onboard` - Improve onboarding experience

### Enhancement
- `/bolder` - Make design more distinctive and memorable
- `/quieter` - Reduce visual noise and distractions
- `/delight` - Add delightful micro-interactions
- `/harden` - Add error handling and edge cases
- `/optimize` - Improve performance

### Adaptation
- `/adapt` - Adapt design for different contexts
- `/overdrive` - Push design to maximum impact

### Learning
- `/teach-impeccable` - Set up design context for the project

## 📚 Core Skill: frontend-design

The main skill includes comprehensive references for:
- **Typography** - Scales, pairing, loading strategies
- **Color & Contrast** - OKLCH, palettes, dark mode
- **Spatial Design** - Grids, rhythm, container queries
- **Motion Design** - Timing, easing, reduced motion
- **Interaction Design** - Forms, focus, loading patterns
- **Responsive Design** - Mobile-first, fluid design
- **UX Writing** - Labels, errors, empty states

## 🚀 Quick Start

1. **Set Design Context** (REQUIRED first step):
   ```
   /teach-impeccable
   ```
   This will gather essential context about your project's target audience, use cases, and brand personality.

2. **Audit Your Current Design**:
   ```
   /audit
   ```
   Get a comprehensive quality report with scores and actionable recommendations.

3. **Apply Fixes**:
   ```
   /normalize
   /polish
   ```
   Fix inconsistencies and apply final polish.

## 🎨 Anti-Patterns to Avoid

Impeccable explicitly warns against common AI design tells:
- ❌ Overused fonts (Inter, Roboto, Arial)
- ❌ Gray text on colored backgrounds
- ❌ Purple gradients and cyan-on-dark color schemes
- ❌ Cards nested inside cards
- ❌ Bounce/elastic easing
- ❌ Glassmorphism everywhere
- ❌ Gradient text for "impact"
- ❌ Generic hero metric layouts
